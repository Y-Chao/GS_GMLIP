Project folder

    
Open or create a project to start. Nothing is stored until a folder is chosen.

    
Everything a project produces is stored in this folder: the structure database, jobs, workflows, the project molecule library, and plugins. A new folder is created if it does not exist. The global database only receives structures you add to it yourself from the Data tab.

    
    

      
      
    

    

  

  
    
Remote hosts

    
A job is uploaded over SSH, submitted to the scheduler, and its structures are merged back into this project while it runs. SSH must work without a password prompt (key or agent). Hosts are stored for all projects.
